IP Info allows you to view all parameters derived from an IP address. 
You can input any IP address to retrieve details such as:
  Country, Region, Continent, State/Province, Postal code, Coordinates (latitude, longitude), 
  Time zone, Offset, Currency, ISP name, ISP organization, Autonomous System (AS) name and number, 
  Mobile IP status (True/False), Proxy status (True/False), and whether the IP belongs to a hosting provider.
